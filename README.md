## Synopsis

[RoostR.js](https://github.com/1pizzateam/RoostR.js) is an open source WebGL 3D engine written in TypeScript to help you develop HTML5 / WebGL applications for desktop and mobile browsers.

## Motivation

The main purpose of this library is to provide a simple, modular way to develop 3D applications for browsers.

## Installation

```bash
$ npm install @1pizzateam/roostr
```
